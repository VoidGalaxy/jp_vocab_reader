## 자료의 위치와 접근 한계

- 제품 코드는 Git 커밋이 현재 구현 기준이다.
- 승인 시안과 게이트 증거는 주로 `references/mockups/`와 `references/plans/`에 있다. 상당 부분이 미추적이며 로컬에만 있다.
- 로컬 앱, 클라우드, 클로드 원격 작업은 파일과 대화가 자동으로 같아지는 것이 아니다. 필요한 문서·캡처만 명시적으로 전달하고 실제 체크아웃을 확인한다.
- 미추적 PNG, QA 기록, `tsconfig.tsbuildinfo`는 제품 커밋에서 제외했다. DB·토큰·`.env`를 인계 자료에 넣지 않는다.
