# Gate C-2 검사표 (구현 시 실행, 지금은 미실행)

작성: 2026-10-10 (v0.1), 보정 v0.2: 2026-10-10. 계약 `CONTRACT.md` v0.2, 계획 `IMPLEMENTATION_PLAN.md` v0.2.

층 구분:
- **U**: 프론트 순수 모듈(node --test)
- **S**: 서버 단위·트랜잭션(세션 전용 SQLite)
- **A**: 실제 API(TestClient 또는 loopback 서버)
- **B**: 실제 브라우저(세션 전용 SQLite 백엔드 + 별도 포트 프론트, 합성 계정)

단계: **a** = C-2a 서버, **b** = C-2b 클라이언트 순수, **c** = C-2c 연결.
PostgreSQL 항목은 보호 검사를 통과한 빈 로컬 DB가 없으면 미검증으로 기록한다.
