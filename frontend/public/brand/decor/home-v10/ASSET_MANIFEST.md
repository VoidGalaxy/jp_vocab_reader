# Home V10 Runtime Assets

`home-v10-scene-desktop.png` (1672x940) and
`home-v10-scene-mobile.png` (941x1672) are opaque, complete scenes.

Each image already contains the oak desk, notebook, blank title note, blank
CTA ticket, blank tabs, Shiori tucked behind the note tape, and all physical
contact shadows. They must be rendered as the sole visual scene base.

Do not extract a transparent foreground, derive alpha from either image, or
add CSS shadows, filters, background patches, or separate Shiori artwork.
Korean/Japanese text, icons, focus states, and interactive hit zones remain
live DOM overlays at the coordinates in
`references/mockups/home-v10-prep/ASSET_ACCEPTANCE.md`.
